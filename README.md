# 韩佑宁｜个人作品集

一个使用 React + Vite 制作的中英双语个人作品集网站，集中展示教育背景、科研经历、实习经历、语言能力与工具能力。

## 在线访问

- 国际公开版：https://youning-han-waseda-portfolio.survive225.chatgpt.site

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 技术栈

- React
- Vite
- CSS 响应式布局与交互动效
